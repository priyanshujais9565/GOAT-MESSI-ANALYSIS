
# ⚽ GOAT Messi Analysis

An interactive **Power BI dashboard** analyzing the legendary career of **Lionel Messi** using **Microsoft Excel**, **Power Query**, and **Power BI**. The project provides data-driven insights into Messi's goals, assists, appearances, competitions, clubs, and seasonal performance through dynamic visualizations.

---

## 📌 Project Overview

This project transforms raw football statistics into an interactive business intelligence dashboard. The data was cleaned and transformed using **Power Query**, organized in **Excel**, and visualized in **Power BI** to uncover meaningful insights about Lionel Messi's career.

---

## 🛠️ Tools Used

- 📊 Microsoft Excel
- 🔄 Power Query
- 📈 Microsoft Power BI

---

## 📂 Dataset

The dataset includes:

- Player Information
- Club Statistics
- Competition Statistics
- Season-wise Performance
- Goals
- Assists
- Appearances
- Minutes Played

---

## 🔄 Data Preparation

- Removed duplicate records
- Handled missing values
- Changed data types
- Renamed columns
- Created calculated columns
- Performed data transformation using **Power Query**

---

## 📊 Dashboard Features

- Total Goals
- Total Assists
- Total Matches Played
- Goals by Competition
- Goals by Club
- Season-wise Performance
- Goal Contribution Analysis
- Interactive Filters & Slicers

## 📈 Key Insights

- Highest goal-scoring seasons
